# 公众号IP文创作工厂

这是一个把个人经验、观点和素材，协作生产成可发布公众号 IP 文章的内容系统。

## 核心模块

```text
选题索引
→ 素材池
→ 协作扩写
→ 成稿区
→ 发布版
→ 配图区
→ 发布包
→ 已发布
→ 数据区
```

## 需要的 skill

- `wechat-article-publisher`
- `skill-runtime-sync`

## 使用方式

1. 把 skill 放到本机运行时目录。
2. 初始化内容工厂目录。
3. 先写素材，再进入协作扩写。
4. 生成发布版、发布包、草稿。
5. 正式发布后回填公开链接，再归档到 `已发布/`。
