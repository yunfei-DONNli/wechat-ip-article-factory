# 对外发布包清单

## 可以公开

- skill
- 内容工厂模板
- 写作资产模板
- public-generic Profile 模板与合成示例
- 文档
- 虚构 demo
- 快速开始说明

## 必须模板化

- 作者风格资产
- 身份基线
- 故事素材库
- 发布记录
- 控制页
- 已发布链接索引

## 不能公开

- 真实收件箱内容
- 真实素材池内容
- 真实草稿编号
- 真实链接
- 账号凭据
- 服务器信息

## 第一版范围

版本：`v0.1.0`

定位：能让别人搭起公众号文章生产系统，但不包含真实后台自动化链路。

## 公开版原则

- 原汁原味：保留流程和门槛
- 去隐私：去掉个人路径、账号、真实素材和真实发布记录
- 可复用：别人能直接照着搭自己的版本
