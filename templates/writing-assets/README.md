# 写作资产模板

写作资产是这套流程的基础。它帮助 AI 保留作者自己的判断、语气、经验和边界，而不是临时拼一篇通用文章。

## 建议先填写

- `作者公众号风格基线模板.md`
- `作者身份基线模板.md`
- `个人故事素材库模板.md`
- `表达边界规则模板.md`

## 使用原则

- 没有真实经验，不要包装成专家观点
- 没有故事素材，不要编故事
- 没有核验来源，不要把判断写成事实
- 已有强判断时，优先做原味增强，不要重写成通用 AI 文

## 每篇文章至少检查

- 这篇文章调用了哪些写作资产
- 哪些资产不适合本篇
- 哪些素材只能做参考，不能强行写入正文
- 是否需要个人故事锚点
