# 内容工厂模板

这是一个个人公众号文章内容工厂的基础目录。你可以直接复制到自己的 Obsidian vault，也可以按同样职责改造成自己的目录结构。

## 目录职责

```text
内容工厂/
├── 素材池/        # 原始想法、截图、链接、事件线索、摘录
├── 协作扩写/      # 输入诊断、MECE 分析、方案卡、候选稿
├── 成稿区/        # 已完成但还未进入发布流程的文章
├── 发布版/        # 锁定标题、结构、正文后的发布稿
├── 配图区/        # 封面、正文图、截图、图片提示词
├── 发布包/        # article.json、content.html、cover、images
├── 已发布/        # 用户确认正式发布后的归档
├── 数据区/写作资产/ # 作者风格、身份、故事、表达边界
└── 选题索引.md
```

## 推荐状态

- `idea`：只是选题或一句判断
- `material`：已有素材但未成文
- `expanding`：正在协作扩写
- `draft`：已有候选稿
- `publish_ready`：发布包准备完成
- `draft_created`：已创建公众号草稿箱草稿
- `manual_package_ready`：无 API，已生成手动发布包
- `published`：用户确认正式发布或已提供公开链接

## 最小闭环

一篇文章至少应该经历：

1. 素材进入 `素材池/`
2. 在 `协作扩写/` 完成输入诊断和方案卡
3. 在 `成稿区/` 形成候选稿
4. 在 `发布版/` 锁定标题和正文
5. 在 `配图区/` 处理封面和正文配图
6. 在 `发布包/` 形成可发布资产
7. 人工确认后归档到 `已发布/`

## 草稿箱 API 说明

公众号草稿箱推送依赖官方 API 权限。很多账号没有这个权限。

- 有 API：可以把发布包推到草稿箱
- 无 API：生成手动发布包，人工复制到公众号后台

不要把 `draft_created` 当成 `published`。
