# 公众号IP文创作工厂

一套把个人经验、观点和素材，协作生产成可发布公众号 IP 文章的内容系统。

## 包含什么

- 公众号文章发布 skill
- 运行时同步 skill
- 内容工厂模板
- 写作资产模板
- demo 示例
- 安装脚本

## 快速开始

```bash
bash scripts/install-skills.sh
```

然后把 `templates/content-factory/` 复制到你的 Obsidian vault，填写写作资产模板，从 demo 开始跑第一篇文章。

## 边界

- 默认只到草稿和人工确认，不自动群发。
- 公开版不包含任何私人素材、真实发布记录或账号凭据。
- `已创建草稿` 不等于 `已正式发布`。
