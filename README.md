# 公众号IP文创作工厂

一套把个人经验、观点和素材，协作生产成可发布公众号 IP 文章的内容系统。

它的核心目标不是让 AI 代替你凭空写文章，而是把你已有的想法拆开、理顺、补齐链路，再组织成一篇更适合公众号发布的文章。

## 这套 skill 真正在做什么

公众号 IP 内容的可信度，首先来自作者自己的行业认知、真实经验和长期观察。

这套流程更适合处理这样的输入：

- 你对某个行业、岗位、工具、产品或业务问题有真实观察。
- 你已经有一个判断，但还没有形成完整文章。
- 你有案例、踩坑、复盘、方法论或反思，但表达还比较散。
- 你希望把个人认知沉淀成持续输出的公众号 IP 内容。

最好的使用方式是：人提供判断、经验、案例和边界，AI 负责拆解、结构化、补链路、做标题、排版和发布闭环。

## AI 在这里做什么

AI 的角色是内容放大器，不是经验替身。它主要帮助你完成：

- 提炼核心判断：把模糊想法收敛成一条明确主线。
- 拆解论证结构：把观点拆成问题、原因、案例、方法和结论。
- 补齐表达链路：让文章从“我知道”变成“读者能理解”。
- 生成标题候选：围绕读者利益、冲突感和传播性生成公众号标题。
- 整理发布资产：准备摘要、封面建议、配图提示、草稿和归档信息。

## 不适合什么情况

它不适合用来伪装专业经验。

如果你对一个行业没有基本认知，也没有一手经验或可靠资料，这套流程最多只能帮你做资料整理和学习笔记，不应该直接包装成权威观点文章。

AI 可以放大表达效率，但不能替代真实认知。文章里最重要的部分，仍然应该来自作者自己的判断、经历和长期积累。

## 包含什么

- 公众号文章发布 skill
- 运行时同步 skill
- 内容工厂模板
- 写作资产模板
- demo 示例
- 安装脚本

## 快速开始

```bash
bash scripts/install-skills.sh
```

然后把 `templates/content-factory/` 复制到你的 Obsidian vault，填写写作资产模板，从 demo 开始跑第一篇文章。

## 推荐工作流

- 先写下你的原始想法、行业判断、案例和素材。
- 用写作资产模板补充你的定位、表达风格、常用故事和观点边界。
- 调用公众号文章发布 skill，把想法拆成文章结构。
- 检查标题、观点、个人故事、配图和发布资产。
- 人工确认后，再进入公众号草稿或发布系统。

## 边界

- 默认只到草稿和人工确认，不自动群发。
- 草稿箱推送依赖公众号官方 API；很多人没有这个权限，所以公开版默认不强依赖这一步。
- 公开版不包含任何私人素材、真实发布记录或账号凭据。
- `已创建草稿` 不等于 `已正式发布`。
