# 公众号IP文创作工厂

把个人经验、行业认知和素材，拆成一篇能发布的公众号 IP 文章。

这套工具不是让 AI 代替你写观点，而是帮你把自己的想法拆开、理顺、补齐，再变成适合公众号发布的内容。

## 适合谁

- 对某个行业、岗位、产品或业务问题有真实观察的人
- 已经有判断，但还没写成文章的人
- 有案例、踩坑、复盘、方法论，但表达比较散的人
- 想把个人认知沉淀成长期输出的公众号 IP 作者

## 这套 skill 的核心原则

公众号内容最有价值的部分，来自作者自己的行业认知、真实经验和长期观察。

AI 的作用是放大表达效率，不是替代经验本身。

## AI 会帮你做什么

- 提炼核心判断
- 拆解文章结构
- 补齐论证链路
- 生成标题候选
- 整理草稿、摘要、配图提示和发布资产

## 不适合什么情况

- 不适合用来伪装专业经验
- 不适合把没有认知、没有一手经验的内容直接包装成权威观点
- 如果缺少行业理解，这套流程最多只能辅助你整理资料和做学习笔记

## 包含什么

- 公众号文章发布 skill
- 运行时同步 skill
- 内容工厂模板
- 写作资产模板
- demo 示例
- 安装脚本

## 快速开始

```bash
bash scripts/install-skills.sh
```

然后把 `templates/content-factory/` 复制到你的 Obsidian vault，填写写作资产模板，从 demo 开始跑第一篇文章。

## 推荐工作流

1. 先写下你的原始想法、行业判断、案例和素材
2. 用写作资产模板补充定位、表达风格、常用故事和观点边界
3. 调用公众号文章发布 skill，把想法拆成文章结构
4. 检查标题、观点、个人故事、配图和发布资产
5. 人工确认后，再进入公众号草稿或发布系统

## 边界

- 默认只到草稿和人工确认，不自动群发
- 草稿箱推送依赖公众号官方 API；很多人没有这个权限，所以公开版默认不强依赖这一步
- 公开版不包含任何私人素材、真实发布记录或账号凭据
- `已创建草稿` 不等于 `已正式发布`
