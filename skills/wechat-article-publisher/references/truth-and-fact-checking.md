# 真实性与事实核验 Gate

## 核心原则

真实性不是发布时才检查。公众号文章要分两段处理：

- 写作阶段事实核验：在方案卡、候选稿或扩写前后，把外部事实、用户判断和未核验占位分开。
- 发布前真实性复核：在发布版锁定、发布包 ready、远端草稿创建前，再检查正文所有确定性事实是否有来源或已降级为个人观察 / 经验 / 判断。

不能等到创建草稿或正式发布时才第一次检查真实性。

## 触发条件

文章出现以下任一内容时默认触发：

- 当前事件、新闻、公司动态、产品发布、政策变化
- 公司 / 产品 / 功能 / 价格 / 排名 / 市场数据
- 技术机制、产品能力、模型能力、工具能力判断
- 命名人物、报告、案例、榜单、论文、官方说法
- 截图中提到的外部事实或截图描述会进入正文
- 标题、摘要、顶部卡片、开头索引依赖某个事实判断
- 用户要求“真实 / 核验 / 查一下 / 搜一下 / 对齐截图”

## 写作阶段事实核验

在方案卡或候选稿前创建 / 更新：

```text
content-factory/material-pool/YYYY-MM-DD_主题/research-brief.md
```

如果历史工作台已有 `research-brief.md`，可以复用，但必须补上当前文章最终使用的事实。

`research-brief.md` 至少区分：

- 用户自己的判断 / 个人体验 / 实测过程
- 已核验事实
- 一手来源：官网、官方文档、公告、产品页、论文、GitHub、后台截图等
- 二手来源：媒体、社区、他人文章，仅作补充或线索
- 冲突、未解项、版本易变项
- 未核验但可保留的观察
- 不能写成确定事实的占位

资料优先级：用户原始材料和 vault 内部资料 → 内部系统资料 → 官方 / 一手来源 → 高质量二手来源 → 开放网络和社交讨论线索。

截图 OCR 或图片内容不是外部事实核验，只能说明“截图显示 / 用户提供截图中出现”。如果要写成外部事实，仍需来源或降级表达。

截图描述必须逐张对齐原图，不能只根据用户笔记里的概括词推断。凡正文要描述截图中的角色、数量、按钮、价格、排名、Agent 名称或操作过程，先读原图 / OCR，再写描述；看不清就写“截图显示不清”或降级为用户观察。不要把“召唤投资天团”这类素材概括，扩写成原图不存在的 Agent 类型或行为。

## 发布前真实性复核

在发布版锁定、HTML / 发布包 ready、远端草稿创建前执行。

逐项复核：

- 标题、摘要、顶部卡片、内容索引中的确定性事实
- 正文每个产品、公司、价格、时间、排名、能力、政策、数据判断
- 图注和截图描述是否和真实截图逐张对应
- 外部链接、历史文章链接是否可复制，失效链接是否已标注或替换
- 未核验事实是否已改成“我看到 / 这次实测 / 按我理解 / 我的判断 / 从截图看”
- 用户原始判断是否被 AI 擅自扩大为行业事实

发布前输出记录必须写明：

- `research-brief.md` 路径
- 已核验事实摘要
- 未核验但保留的观察
- 已降级写法
- 仍需人工确认的事实 / IP / 版权风险

发布包进入 ready 前，`article.json` 必须记录：

```json
{
  "truth_check": {
    "triggered": true,
    "research_brief": "content-factory/material-pool/YYYY-MM-DD_主题/research-brief.md",
    "publish_preflight_review": true,
    "unverified_claims": [],
    "downgraded_claims": [],
    "central_unverified_blockers": [],
    "human_confirmation_required": []
  }
}
```

如果未触发事实核验，必须写：

```json
{
  "truth_check": {
    "triggered": false,
    "reason": "纯个人经验复盘，不含外部事实判断"
  }
}
```

`publish_precheck.py` 会阻断缺少 `truth_check`、缺少已触发核验的 `research_brief`、未完成 `publish_preflight_review`、存在中心事实阻塞项，或有未核验事实但没有降级 / 人工确认记录的发布包。

## 不允许

- 草稿创建时才第一次做事实核验
- 只因为用户原文这么写，就把外部事实写成确定事实
- 用 AI 常识替代来源
- 把截图 OCR 当作已核验外部事实
- 发布前只检查排版，不检查事实
- 为了标题吸引人夸大事实边界

## Hard Stop

如果主判断依赖的中心事实无法核验：

- 停止进入发布包 ready / 远端草稿
- 改写为个人体验、观察或判断
- 或记录未核验项并请求用户确认

如果不影响中心论点，可以保留为占位、脚注式风险或删去，但必须记录处理结果。
