# 方案卡三方向证据保留规则

协作扩写不是只保存最终选择的方案。为了复盘 agent 是否真的做过创造运行时发散，必须保留三方向探索证据。

## 必须保留的文件

每篇协作扩写文章至少保留：

```text
协作扩写/workbench/YYYY-MM-DD_主题/
├── option-card.md              # 用户可读的方案卡汇总
├── direction-a.md               # 熟悉但更清楚
├── direction-b.md               # 明显差异化
├── direction-c.md               # 大胆但可理解
└── decision-record.md           # 用户选择、融合关系、舍弃理由
```

如果沿用旧目录结构，至少要在 `option-card.md` 内完整保留 A/B/C 三个方向，而不是只保留 selected 方案。

## 每个方向必须记录

- 标题角度
- 核心论点
- 开头策略
- 结构大纲
- 个人锚点策略
- 配图策略
- 创造运行时：稳定核心、偏离点、新颖度、方法论、情绪锚点、风险
- 为什么保留 / 融合 / 放弃

## 禁止做法

- 用户选了 A，就删除 B/C。
- 只保存“推荐方案”，不保存比较依据。
- 方案卡只换标题，结构和情绪没有差异。
- 后续改稿时无法追溯用户为什么选这条主线。

## 最小检查

进入候选稿前检查：

```text
三方向证据：已保留 / 部分保留 / 缺失
用户选择记录：已记录 / 未记录
融合或舍弃理由：已记录 / 未记录
```
