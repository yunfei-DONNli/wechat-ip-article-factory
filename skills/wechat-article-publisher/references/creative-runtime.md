# 创造运行时

这是一层“创作发散层”，只用于公众号文章的选题、结构、标题、正文表达和配图创意，不进入发布工程链路。

## 使用时机

必须在这些场景调用：

- 生成 MECE / 金字塔后的方案卡
- 生成标题候选
- 重大改稿、重写开头、重排结构
- 生成封面 / 正文图提示词
- 用户反馈“太平、太 AI、没差异、不像我、像第三方评论”

不得用于：

- 发布包字段生成
- HTML 兼容性修复
- 草稿箱上传
- 链接回填
- 预检脚本
- Git / 远端 runner 操作

这些阶段必须稳定、确定、可复现。

## 默认创造模型

采用“有控制的偏离”：

- 先定义稳定核心，再做发散
- 允许结构、标题、视觉和叙事方式变化
- 不允许偏离核心判断、作者身份、事实边界和长期审美
- 默认变异强度：中低，约 `0.35`
- 默认新颖度：明显差异化，但不追求怪

## 稳定核心

每次发散前先写清：

- 核心判断：这篇文章最不能丢掉的一句话
- 作者位置：为什么由作者来说
- 读者问题：读者正在误解、焦虑或卡住什么
- 情绪锚点：荒诞、警惕、兴奋、踏实、焦虑、释然等
- 事实边界：哪些事实不能编、不能夸、不能偷换
- 不可改内容：用户原话、核心段、明确偏好、禁改表达

## 多方向生成

默认至少给 3 个方向，不要只给同一方向的深浅版本。

每个方向必须包含：

- 稳定核心：继承了什么
- 偏离点：从结构、情绪、叙事、符号、读者对象或方法论中的哪一项偏离
- 新颖度等级：熟悉 / 轻度新鲜 / 明显差异化 / 大胆
- 方法论：本方向主要使用哪 1-3 个方法论
- 情绪锚点：读者为什么会有感觉
- 结构差异：不是只换标题，而是文章组织方式不同
- 风险：可能偏题、过猛、过抽象、过技术、过营销的地方

推荐组合：

- 方向 A：熟悉但更清楚，适合稳妥发布
- 方向 B：明显差异化，适合增强传播
- 方向 C：大胆但可理解，适合突破同质化

## 可用方法论

按任务动态选择，不需要全部使用。

- 第一性原理：拆本质、重建结构
- Design Thinking：用户体验、读者路径
- Jobs To Be Done：读者为什么要读、读完要改变什么
- Systems Thinking：系统关系、长期影响
- Narrative Design：叙事体验、情绪节奏
- Behavioral Psychology：行为触发、误判来源
- Semiotics：符号、隐喻、关键词的社会含义
- Aesthetic Theory：风格协调、审美一致
- SCAMPER：快速生成标题、结构、表达变体
- Morphological Analysis：多维组合方案
- Speculative Design：未来推演、反事实场景

输出方案卡、标题或配图提示词时，要标出当前使用的方法论。

## 反同质化检查

每次创作输出后检查：

- 是否只是行业平均话术
- 是否只是公众号模板标题
- 是否缺少作者自己的判断和偏见
- 是否缺少具体现场、截图、案例或身体感
- 是否为了创新制造噪音
- 是否把文章写成第三方行业评论
- 是否过度抽象，没有可感知的情绪锚点
- 是否出现 AI 套话、万能句、空泛趋势判断

修正方式：

- 引入非对称结构：不要所有段落都同样整齐
- 保留创作者偏见：明确“我更担心 / 我更看重 / 我不赞成”
- 注入人类不完美：允许短句、停顿、现场判断
- 注入文化特征：保留中文互联网语感、企业现场语感、作者长期词汇
- 强制结构差异：至少一个方向从不同叙事入口展开

## 标题发散规则

标题候选不要只换同义词。至少覆盖：

- 熟悉判断型：读者一眼懂
- 反常识型：打破误解
- 人格化判断型：有作者立场
- 冲突型：指出 A 与 B 的矛盾
- 系统型：从事件推到长期结构

每个标题仍必须忠于正文核心，不为了点击率偏题。

## 配图发散规则

配图提示词要先定画面，再定概念。

至少生成 2-3 个视觉方向时，差异应该来自：

- 真实场景 vs 抽象隐喻
- 商业评论感 vs 手绘解释感
- 证据截图 vs 情绪插图
- 克制高级 vs 轻微荒诞

不要用抽象词堆 prompt，例如“平台 + AI + 工作流放大器”。

## 输出格式

用于方案卡时，加入：

```text
创造运行时：已调用
稳定核心：
偏离点：
新颖度：
使用方法论：
情绪锚点：
反同质化处理：
风险：
```

用于标题时，加入：

```text
标题发散：熟悉 / 明显差异化 / 大胆
推荐标题：
推荐理由：
风险：
```

用于改稿时，加入：

```text
改稿偏离点：
保留的稳定核心：
去同质化动作：
可能损失：
```
