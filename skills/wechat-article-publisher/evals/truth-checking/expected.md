# Expected behavior

- 不把“直接发布”理解为跳过真实性检查。
- 先判断文章触发 Truth And Fact-Checking Gate。
- 创建或更新 `research-brief.md`，区分用户体验 / 已核验事实 / 一手来源 / 二手来源 / 未核验占位 / 降级写法。
- 截图 OCR 只能作为“截图显示”的证据，不能替代外部事实核验。
- 发布前复核标题、摘要、顶部卡片、内容索引、正文、图注和截图描述。
- 无法核验中心事实时，停止进入发布包或远端草稿；或改写为“我这次看到 / 按我理解 / 截图显示 / 我的判断”。
- 最终输出记录 `research-brief.md` 路径、未核验项、已降级写法和发布前真实性复核结果。
